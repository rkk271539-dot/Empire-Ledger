# Version 0.1 — Foundation Release Notes

## Scope & Deliverables
The goal of v0.1 is to establish a solid, type-safe, production-ready foundation according to Section 3 and Section 17 of `GAME_SPEC.md`:
1. **Scaffold & Architecture**:
   - Modern React 18 + Vite + TypeScript application with Tailwind CSS styling and Inter typography.
   - PWA ready with Web App Manifest and mobile viewport meta tags.
   - GitHub Pages deployment workflow configured in `.github/workflows/deploy.yml` with relative base path.
2. **Headless Engine**:
   - Pure TypeScript headless engine in `/src/engine` with zero React or DOM dependencies.
   - Deterministic tick pipeline: `tick(state, seed)`.
   - Command pattern: `reduce(state, command) -> { state, events }`.
3. **Mandatory Dynamics Math Toolkit (Section 18A)**:
   - `dynamics/rng.ts`: Seeded PRNG (Mulberry32) with named independent streams (`Rng.stream(seed, name, day)`), Box-Muller normal, Marsaglia-Tsang gamma, beta, student-t, laplace, lognormal, poisson, and pareto.
   - `dynamics/stochastic.ts`: OU exact discretization, Markov regime switching (calm/normal/stressed), Cholesky decomposition, and stress-adjusted correlation matrices.
   - Core dynamics scaffolding: `stockModel.ts`, `earningsModel.ts`, `projects.ts`, `trustModel.ts`, `lean.ts`, `stats.ts`.
   - ESLint rule enforcing prohibition of `Math.random` and `Date.now` within `/src/engine`.
4. **Time System**:
   - Day counter, 4 slots (Morning, Noon, Evening, Night), calendar date calculations, and 60-day announcement cycle countdowns.
5. **Persistence**:
   - IndexedDB multi-slot storage (`idb`) with localStorage fallback and JSON file export/import.
   - State versioning with `schemaVersion: 1`.
6. **Mobile-First Fintech UI Shell**:
   - Top status bar with tabular numerals, date, cash, net worth, and announcement countdown.
   - Day advancement controls (advance slot, skip 1 day, skip 1 week, auto-play).
   - Bottom tab bar for mobile screens (Dashboard, Company, Market, People, More...) and sidebar layout for desktop.
   - Complete navigation across all 10 planned screens: Dashboard, Company, Market, People, Institutions, Startups, Wife, News, Finance, Settings.
   - Settings tab supporting save slots, save/load operations, theme toggle, and number format toggle (Indian Lakh/Crore vs Standard Million/Billion).
